Диаграммыг харах
VS Code дээр PlantUML (jebbs) extension-ийг суулгана.
.puml файлыг нээнэ.
Option + D (Mac) эсвэл Alt + D (Windows) дарна — диаграмм баруун талд гарч ирнэ.

Java суулгаагүй бол VS Code-ын settings.json-д дараах тохиргоог нэмнэ:

json
"plantuml.render": "PlantUMLServer",
"plantuml.server": "https://www.plantuml.com/plantuml"

Эсвэл кодыг plantuml.com/plantuml дээр хуулж тавиад онлайнаар харж болно.
